## ARCHITECTURE (3 LAYERS)
────────────────────────────────────────

1. **EVENT STORE (Source of Truth)** — `engagement_events` immutable append-only log
2. **STATE PROJECTION (Derived)** — `buildEngagementState(events)` pure reducer
3. **AI (Advisory)** — `generateInsightsFromEvents(events)` read-only analysis

### Flow (Dashboard Load)
```
getDashboardData()
  → getEvents(trainerId)                # events = truth
  → buildEngagementState(events)        # pure projection
  → generateActionQueue(dto, insights)  # deterministic, no DB
  → filterByProjection(runtime, proj)   # compare vs events
  → appendEvents(ACTION_CREATED)        # new actions only
  → getTrainerDailyFeed(filtered)       # render
  → computeOutcomeFromEvents(events)    # derived analytics
  → generateInsightsFromEvents(events)  # read-only AI
```

### Guarantees
- Events = ONLY source of truth — no dual writes
- `buildEngagementState()` is a deterministic reducer — replay always produces identical state
- `engagement_actions` table removed from data flow — events only
- `appendEvents()` uses `event_id` UNIQUE constraint for idempotent retries
- AI never writes to DB — `generateInsightsFromEvents()` is pure computation
- No hidden reconciliation logic — `filterByProjection()` is a simple map lookup
