# Tailwind Design System

Build production-ready design systems with Tailwind CSS, including design tokens, component variants, responsive patterns, and accessibility.

## Use this skill when

- Creating a component library with Tailwind
- Implementing design tokens and theming
- Building responsive and accessible components
- Standardizing UI patterns across a codebase
- Setting up dark mode and color schemes

## Instructions

1. Clarify goals, constraints, and required inputs
2. Assess scope and identify key decisions needed
3. Apply Tailwind best practices and domain-specific expertise
4. Follow established patterns and conventions for design tokens
5. Validate results against requirements and accessibility standards
6. Document decisions and rationale

## Core Areas

### Design Token Management
Create and manage design tokens including color systems, typographic scales, and spacing conventions. Enable consistent mapping from design to code with multi-theme support.

### Component Variant System
Build flexible component variants using Tailwind's variants and custom configuration. Create reusable component patterns that improve maintainability.

### Responsive and Accessible Design
Ensure components work across devices with responsive patterns while integrating accessibility standards.
